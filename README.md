# SPILL≋
My project [2048 AI](https://angelazqian.github.io/2048-AI/) is being displayed at [spill≋](https://spill.purduehackers.com/)!!!\
The project is being framed along the lines of "Here's a 2048-playing AI, grab the joystick and disrupt the game" and I managed to get my hands on an old-school video game joystick and a CRT monitor to display it on. Which is. So cool!!!\
Since it's being shown as a game installation instead of an interface where you can try out various AI models, I made some tweaks to the so that it can be used with only a joystick to represent the four directions.
